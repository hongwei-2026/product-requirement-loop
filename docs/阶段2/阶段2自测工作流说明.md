## 改了 yaml 之后要做什么？

1. 保存 `project/product-requirement/specification.yaml`  
2. 同步内嵌（方便 file:// 打开）：  
   ```bat
   python scripts\sync_spec_embed.py
   ```  
3. 跑自测：  
   ```bat
   python scripts\verify_stage2.py
   python scripts\verify_all.py --write-reports
   ```  
4. 用 `start-with-ai.bat` 打开 review.html，展开 **「Loop 定义」** 肉眼对一遍
