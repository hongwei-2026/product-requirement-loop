## 3 个一分钟自测（不懂技术也能做）

### 自测 A：打开官方日志

1. 打开：https://github.com/quanttide/quanttide-journal-of-product-development/blob/main/qtcloud-product/2026-08-19.md  
2. 搜索「捕捉用户故事」  
3. 再打开本地 `project/trials/case-01/input/journal-raw.md`  
4. **能对上** → 输入来源可信

### 自测 B：打开官方 JSON

1. 打开：https://github.com/quanttide/quanttide-profile-of-product-development/blob/main/qtcloud-product/requirement.json  
2. 找到「捕捉用户故事」下的三条，是否都以「用户要」开头  
3. **是** → 输出格式有据可依

### 自测 C：打开验收页（阶段 4 后用，阶段 0 可先预览）

1. 用浏览器打开 `project/trials/case-01/review.html`  
2. 看左边原文、右边故事列表的设计  
3. **能看懂左右对照** → 后期你不用懂 JSON 也能验收
