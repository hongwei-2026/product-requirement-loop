## 改了提示词之后要做什么？

1. 改 `project/product-requirement/prompts/*.md`  
2. 同步试点副本：  
   ```bat
   copy /Y project\product-requirement\prompts\*.md project\trials\case-01\prompts\
   ```  
3. 重跑试跑（需 Agnes）：  
   ```bat
   project\.venv\Scripts\python.exe scripts\run_stage3_trial.py
   ```  
4. `python scripts\verify_stage3.py`
