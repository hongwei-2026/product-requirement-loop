## LLM：为什么默认 Agnes？

| 选择 | 说明 |
|------|------|
| **本期默认 `LLM_PROVIDER=agnes`** | 免费试用，阶段 0 验收页 + 阶段 4 Loop 同一套 |
| **保留 deepseek / openai** | 改 `.env` 即可，不用改 `implementation.py` 业务逻辑 |
| **商业以后** | 换 Key 和 PROVIDER，不绑死 Agnes |

配置入口：`project/llm_config.py` + `project/.env`
