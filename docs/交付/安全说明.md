# 安全说明（防未授权访问 / 误暴露）

> 这不是「扫密钥」 alone，而是：**别人能不能从外面闯进你的产品页面和接口**。

## 已做的防护

| 能力 | 说明 |
|------|------|
| **只绑本机** | 默认监听 `127.0.0.1`，外网/同网段电脑默认访问不到 |
| **登录门禁** | 工作台与业务 API 需登录；未登录返回 401 |
| **密码不存明文** | 使用 PBKDF2 哈希（`auth_passwords.py`） |
| **会话 Cookie** | `HttpOnly` + `SameSite=Lax`，降低脚本偷 Cookie 风险 |
| **登录限流** | 同一来源短时间多次失败会 429，减慢撞库 |
| **可关注册** | `SECURITY_DISABLE_REGISTER=1` 后只能用已有账号 |
| **路径防护** | `/report/` 禁止跳出文档目录 |
| **安全自检** | `python scripts/verify_security.py`（已进 CI） |

## 你需要知道的边界

1. **演示账号 `demo / demo1234` 是给实训用的**。只要服务只在本机，外人进不来；若你改成局域网开放，等于把门钥匙挂门口。  
2. **不要设置 `SECURITY_ALLOW_LAN=1` / `BIND_HOST=0.0.0.0`**，除非你明确知道风险。  
3. **`.env` 里的 API Key 不要发给别人、不要提交 Git**。
