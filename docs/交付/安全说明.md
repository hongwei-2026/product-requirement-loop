# 安全说明（防未授权访问 / 误暴露）

> 这不是「扫密钥」 alone，而是：**别人能不能从外面闯进你的产品页面和接口**。

## 已做的防护

| 能力 | 说明 |
|------|------|
| **只绑本机** | 默认监听 `127.0.0.1`，外网/同网段电脑默认访问不到 |
| **登录门禁** | 工作台与业务 API 需登录；未登录返回 401 |
| **密码不存明文** | 使用 PBKDF2 哈希（≥10 万次迭代，`auth_passwords.py`） |
| **会话 Cookie** | `HttpOnly` + `SameSite=Lax`，降低脚本偷 Cookie 风险 |
| **登录限流** | 同一来源 60 秒内最多约 12 次登录/注册尝试，超限 429 |
| **响应头** | `nosniff` / `DENY` 嵌框 / `no-store` / `Permissions-Policy` / `COOP` |
| **可关闭注册** | `SECURITY_DISABLE_REGISTER=1` 后只能用已有账号 |
| **路径防护** | `/report/` 禁止跳出文档目录 |
| **出站 URL** | 同步/拉取仅允许 `https://` |
| **定稿门禁** | finalize 前强制 stories check，不通过不能入库 |
| **安全自检** | `verify_security.py` + CI（含 bandit medium+） |
| **踩坑回流** | `verify_lessons.py`：项目过程中真实出过的问题固化成 CI 回归门禁 |

## 你需要知道的边界

1. **演示账号 `demo / demo1234` 是给实训用的**。只要服务只在本机，外人进不来；若你改成局域网开放，等于把门钥匙挂门口。  
2. **不要设置 `SECURITY_ALLOW_LAN=1` / `BIND_HOST=0.0.0.0`**，除非你明确知道风险。  
3. **`.env` 里的 API Key 不要发给别人、不要提交 Git**。
